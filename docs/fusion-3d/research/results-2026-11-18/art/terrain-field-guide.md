# Landscape production field guide

This extends the programme’s 28 landscape families with buildable scene briefs. The labels T01–T28 are Fusion’s routing system. Several historical regions combine multiple treatments. Use the source title, branch, environment and object ID on the evidence row before mapping it to a Fusion kit.

## Which source records exist

The classic extraction contains **619 template declarations and 67 terrain-prop declarations**. Tiberian Dawn contributes 217 templates and 32 props. Red Alert contributes 402 templates and 35 props. Counts include distinct constructor symbols that share an INI ID. Tiberian Dawn’s Empty and Clear both declare CLEAR1 with a jungle bit. That flag gives two memberships and supplies no evidence of a complete retail jungle theatre. Red Alert’s AntHill is conditional on FIXIT_ANTS. Retain that condition. Each output supplies a source line in a versioned source file. For the row’s exact URL, append `#L` and its source line to the source listed in the summary. [Classic source locator and counts](classic-terrain-summary.json)

Tiberian Dawn’s template arguments distinguish primary land, alternate land, width, height and a list of alternate tile indices. Preserve irregular multipiece shorelines. Never force a rectangular tile’s entire area to adopt the same movement surface. Red Alert’s CDATA declaration only gives enum, theatre mask, INI ID and display token. Source dimensions or movement rules for Red Alert require its tile metadata and runtime loader. The prop tables encode occupied and visually overlapping cells independently. Each `x:y` pair is a local cell offset relative to the prop origin, independent of the centre-base sprite offset. A TD T01 tree occupies (0,1) and overlaps (0,0) and (1,1). The TD SPLIT2 and SPLIT3 props explicitly declare the spawning flag. RA distinguishes water-based props. Keep a null historical value empty when one title does not declare that property. ## Which expansion art can reuse a source study

A direct comparison keyed by case-sensitive relative path and object ID found 929 shared TW/KW scenery declarations, 75 KW-only and 8 TW-only. Of the shared rows, 774 have identical source blobs. Another 155 changed source bytes, including one with different fields in this index: **Egyptian_Market_02**. The TW row inherits BaseCivilianStructureNoGarrison and names one local model. KW changes the parent to BaseCivilianStructure and adds local DAMAGED, REALLYDAMAGED and RUBBLE appearances, animation references and dust emitters. Give the variant its own production brief and interaction review. The 154 other byte changes may affect unextracted fields; preserve both locators. [TW](sage-scenery-tw.tsv) · [KW](sage-scenery-kw.tsv)

RA3 and Uprising share the same 3,502 strict path/ID keys and every selected visual field matches. Of those, 3,118 have an identical source blob and 384 differ in unselected content or formatting. In the scoped terrain material collection, every one of RA3’s 406 IDs and four selected attributes remains equal in Uprising, which adds Dirt_Sakhalin01. This supports genuinely shared model briefs while keeping both release-specific provenance and a separate material review for Sakhalin. ## Original environment briefs

Build a 32 × 32-cell inspection chunk per family at first. Put a fixed north arrow, common 1-cell marker and the same original infantry, vehicle and harvester silhouettes on the review layer. Keep persistent render data separate from surface IDs, connectivity, resource masks and visibility. Each variation must include edge joins, a traversable lane and a turn large enough to show the representative mover. Lanes and contrasts below are Fusion art-direction proposals.

## Bridge artist’s handoff

The [original four-stage model](bridge-study.gltf) and [comparison board](bridge-state-board.jpg) show how the same centre span can communicate intact, damaged, missing and rebuilding at one tactical camera angle. The common scene includes a metric deck and water plane. The [browser readback](bridge-study-verification.json) found a centre-deck hit in the first two scenes and water in the latter two. This is a test of visual geometry. The [transaction oracle](../foundation/bridge-oracle-results.json) separately exercises the authored Fusion proposal.

1. Build a left and right abutment, each with lip, footing, approach seam and signed deck socket. Author a 1-span and a 3-span assembly, a pier, a repair hut and neutral visual scaffold. Record both endpoints’ coordinates and deck top in metres. Follow the programme’s existing geometry and crossing rules.
2. Create intact, damaged, absent, repairing and restored presentations with the same deck-space bounds. Damaged must still show a continuous wheel path. Absent must expose the water/valley through the missing middle. Move rubble toward piers or banks. Keep the profile’s open channel clear.
3. Send events by stable span/job IDs and topology revision. Interrupted collapse emits dust once. A subsequent camera visit shows the recorded stable state. Build a partial assembly for a single missing span; neighbouring deck survives. Only successful job completion promotes the previously absent deck to traversable.
4. Capture north and diagonal views of traffic over/under, partial destruction, a civilian in the repair approach, enemy denial, abort, recovery after save/rejoin and a fog edge. Deliver a side elevation with clearances, top-down surface-picking overlay, contact sheet at game zoom, actor/checksum trace and paired high/low-quality images. Technical approval requires deterministic route results and no visible entry onto a missing span.

Kane’s Wrath Bridge1.xml declares separate end and bridge objects and locally declares model states including DAMAGED, REALLYDAMAGED and RUBBLE in this file. Study the state separation while keeping the programme’s engineer, timing, topology and refund rules in their own versioned profile.
