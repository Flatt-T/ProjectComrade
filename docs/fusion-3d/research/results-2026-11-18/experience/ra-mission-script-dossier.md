# How the original Red Alert demo scripts three missions

The English Windows 95 demo contains three format-3 mission records. The attached graph resolves all 131 trigger definitions and 58 team definitions from those records against Electronic Arts’ published Red Alert source. The source provides the meaning of opcodes and the conditions for execution. A full playthrough of each chain in the archived demo remains unverified. ## What happens in the missions

**ALLY2 gives the convoy separate arrival and destruction outcomes.** Team slot 0, `trks`, belongs to England and contains three trucks (`TRUK`). Its ordered moves target waypoints 1, 2, 3, 4 and 25. Trigger `win` checks event 23 (`TEVENT_LEAVES_MAP`) for that team type, then requests action 1 (`TACTION_WIN`) for the Greece player. The published event implementation requires a team of the matching type that is both empty and flagged as leaving the map. The team also references trigger slot 1, `los2`, which waits for its destruction attachments and requests `TACTION_LOSE` for Greece. A separate `win2` trigger dispatches speech 41 followed by a reinforcement request for `trks`. Its prerequisite has a source ambiguity described below. [Team exit check](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TEVENT.CPP#L318) · [Player outcome dispatch](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TACTION.CPP#L601)

**ALLY5 ties evacuation to the last of four SAM sites.** Structure records 3, 4, 44 and 45 identify USSR `SAM` at cells 6118, 6105, 7641 and 7652. All reference the same semi-persistent `evac` trigger. The runtime detaches each destroyed object and decrements the shared attachment count. After the last one, the two enabled actions request reinforcements for team slot 0, also named `evac`, then display message 16. The team belongs to `HOUSE_GOOD`, contains one `TRAN`, originates at waypoint 17 and has one move order to waypoint 0. Physical arrival depends on reinforcement creation and movement. Both actions are attempted in order, including when the reinforcement action returns failure. [Shared attachment and action dispatch](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TRIGGER.CPP#L277) · [Reinforcement action](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TACTION.CPP#L671)

**SOVIET2 uses the same trigger system for a bridge and for defeat.** Four Spain structures carry volatile trigger `Brdg`, three `BRL3` at cells 8261, 8388 and 8392 and one `BARL` at 8265. The first qualifying destruction dispatches two forced triggers in order, slot 1 `det1` and slot 2 `det2`. Both children have no natural event. Each contains two `TACTION_DESTROY_OBJECT` actions. Their recorded cell assignments are 8644, 8645, 8646 and 8517, 8518, 8519 respectively. On a forced call the runtime uses the trigger instance’s stored cell. The action calls the bridge-destruction routine for a nonzero cell. The six map assignments therefore give locations to inspect. The number of independent spans that collapse requires the map’s bridge geometry and an observed or instrumented run. Separately, USSR structure 34, a forward command building (`FCOM`) at cell 10284, carries trigger `los1`. Its destruction requests defeat for USSR followed by message 54. [Forced trigger and win/loss actions](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TACTION.CPP#L584) · [Forced cell selection](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TRIGGER.CPP#L235) · [Bridge dispatch](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TACTION.CPP#L687)

## A discrepancy that changes the convoy prerequisite

`ALLY2.win2` has trigger house USSR, event control AND and two `TEVENT_ALL_DESTROYED` events with raw data 2 (USSR) and 9 (`HOUSE_BAD`). The editor declares that this event needs a house operand. The published dispatcher passes the trigger’s own house into each event evaluator. That evaluator selects the passed house, tests its active building, unit, infantry and vessel scans, and does not consult the event’s house operand in this branch. A literal implementation therefore checks USSR twice. To decide compatibility for the demo executable, keep a `HOUSE_BAD` object active, clear USSR’s eligible scans, and observe whether speech 41 and the convoy request fire. Repeat with USSR active and `HOUSE_BAD` cleared. Until then, preserve both raw operands and distinguish source behavior from any design inference about two hostile factions. [Editor operand declaration](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TEVENT.CPP#L563) · [House passed to both events](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TRIGGER.CPP#L229) · [Active-scan predicate](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TEVENT.CPP#L457)

## Reproduction and field rules

From this research directory’s parent, run the following with the locally acquired archives. The program only reads them. The resulting JSON contains the commit, the demo member hash, original MIX byte offsets, indexed team/trigger definitions, typed operands, ordered team missions, waypoint cells, and per-trigger attachment counts with up to four examples per class. The `*_index` fields retain physical INI entry order. Some game data union fields are signed renderings of narrow values. For instance, raw values −255 and −254 have low bytes 1 and 2 matching Greece and USSR. Preserve raw values alongside a labeled interpretation. A negative team/trigger reference is a separate absent-reference field. [Trigger reader](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TRIGTYPE.CPP#L1935) · [Action operand union](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TACTION.H#L109) · [Team reader](https://github.com/electronicarts/CnC_Red_Alert/blob/0dc09bb1d6188d1ec79ab4765b22a48b75ffee32/CODE/TEAMTYPE.CPP#L1660)

```bash
python experience/ra-mission-reader.py EA-Red-Alert-source.zip ra95demo.zip \
```
