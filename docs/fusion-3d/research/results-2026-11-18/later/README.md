Five publisher XML trees were read file-by-file at EA commit `3aad8e412961ab543192ae70f8503dc8e178e095`. The input is the [official mod-support release](https://github.com/electronicarts/CnC_Modding_Support/tree/3aad8e412961ab543192ae70f8503dc8e178e095). The denominator is a declaration occurrence in that title, keyed by source path, line and declared ID. One object ID can have map overrides, alternative declarations and inherited versions. The command target count includes specialist/purchased forms and support objects across all inspected modes. Animation-state occurrences include records expanded from referenced fragments and empty, manual, formation and non-playing states. A state count alone cannot determine the number of distinct clips to author. The corresponding exact data tables are [TW](tw-source-facts.zip), [KW](kw-source-facts.zip), [RA3](ra3-source-facts.zip), [Uprising](uprising-source-facts.zip) and [C&C4](tt-source-facts.zip).

## Reading a record

1. Start with the per-title production TSV. Find the exact source ID, side and declared producer(s). The **both endpoints** column restricts this to source definitions discovered by walking the released Static, StaticGameObjects and global XML roots. The all-producers column also includes campaign/test/map variants. Consult the [menu matrix](producer-menus.tsv) for other options on the same factory. An absent entry means no matching production edge in that specified graph. Other granting paths, garrison spawns, transformation, capture, scripted activation and patch versions need their own evidence.
2. Open `production-links.jsonl`. Follow the producer → command set → individual command → target chain. Each row names the source location for the membership and command, inherited-set flags, and the resolved target where unique. Menu membership plus explicit build command is stronger than a cost field or a unit-looking filename. It is still a source declaration. Prerequisites, unlocks, maps, selected mode, captured production, upgrade-based set swaps and gameplay guards can change the player's final legal menu.
3. Look up the specific declaration in `objects.jsonl`. Each row gives the local source fields, inherited scalar origins, actual source ancestors and the status of parent resolution. Read the associated body, prerequisite, account, movement, armor, weapon-slot, model, clip, audio, geometry and behaviour records. Use `parameters.jsonl` and `defines.jsonl` to inspect referenced external weapon, locomotor, armor, power and upgrade definitions. For example, a resource account expression with value zero in C&C4 is distinct from its command point requirement.
4. Review each model condition, animation condition, transition, playback mode, clip event frame and attachment bone. Use these as source evidence for an original model or rig. No audiovisual files are embedded. Relative and DATA: XML links and XPointer-selected source fragments are included where they resolve. The receipt is in `xi-inclusion-edges.jsonl`; failures stay visible in `xi-exceptions.jsonl`. A missing declaration in the leaf can be inherited from a parent. Expand the parent and verify the asset compiler’s merge/replace rules before claiming that a leaf has no animation or ability.
5. Pair each row with the title/build observation needed for release. Preserve source expressions and units exactly until the profile’s conversion rules are established. Definition visibility, an editor label, a source file or a stat alone does not certify public skirmish availability, animation frame rate, actual frame timing or permission to ship an asset.

## Integrity and limits

The five title directories expose 26,048 XML files. After documented lexical normalization, 16 files still fail strict parsing. Four games contribute template or fragment exceptions; C&C4 also contains malformed entries in its Obsolete tree and a base civilian definition. Each exception and immutable Git blob hash is recorded in the title archive. C&C4 additionally has 34 unresolved XInclude occurrences. Ambiguous parents and cycles are recorded per source row rather than replaced with inferred data. For scalar lookups, the parser prefers a unique declaration, same source, explicit include, or unique declaration in the static include walk; map and expansion overlay precedence still requires the actual compiler or reference build. The source walk includes XML links and does not execute the asset compiler, resolve arbitrary macros/scripts, prove mesh/clip content, account for all patch overlays, or test a live client. The archive does not establish an exact retail patch match by itself.

Each title has a compressed tabular disposition ledger (such as [TW declarations](tw-object-dispositions.tsv.gz)) for *every extracted occurrence*. Labels distinguish map-scoped entries, obsolete-directory candidates, templates, linked production and static or other unclassified availability. A file-based disposition remains provisional until the source-to-shipped comparison. The [summary](sage-summary.json) and [disposition counts](disposition-counts.json) retain the denominators. No source-only row is automatically approved as a release entry. Prioritize full shipped observations for contested map variants, upgrade-conditional command sets, transformed/garrison cases, campaign-only content and the declared XML/parent exceptions. Record the product/build, map, faction, selected orders, unlocks, expected state, observed state and evidence before closing a title's retail census.

### Reproduce

Use Python with `lxml` and the official [pinned ZIP](https://codeload.github.com/electronicarts/CnC_Modding_Support/zip/3aad8e412961ab543192ae70f8503dc8e178e095). The extractor verifies the archive prefix, hashes source bytes as Git blobs, disables network and entity resolution during XML parsing, and writes deterministic member paths, ordering and timestamps. The scripts require one archive read and local output storage.

```sh
python extract_sage.py official-source.zip output
python build_research_views.py official-source.zip output
```

A JSONL line is a research record. To examine the declared and inherited scalar fields separately from the authored animation states, open `tw-source-facts.zip` and find `AlienAnnihilatorTripod` in `objects.jsonl`, using the faction source path rather than a map override. Follow `production-links.jsonl` for producers and the PDF/manual or a shipped build for availability. The receiving agent must check the archived file's hash and obey asset, soundtrack and trademark provenance gates.
