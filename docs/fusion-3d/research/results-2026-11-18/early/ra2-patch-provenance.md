# Red Alert 2 1.006 and Yuri’s Revenge 1.001 English patch evidence

The English Windows Yuri’s Revenge 1.001 patch contains an independently recoverable **RULESMD.INI**. All 1,477 named sections are present in the existing YR comparator. Of those, 1,452 have identical ordered key/value lists after removing comments and surrounding whitespace. **25 sections differ in actual values or key presence.** None differ solely in ordering. For example, the official CALA05 has CanOccupyFire=yes while the comparator lacks that field. Use the source-specific differences when assigning YR model, voice, weapon and gameplay work. A whole-file equality claim for the comparator would be incorrect. [Per-section hashes and exact changed key/value pairs](ra2-patch-findings.json)

**Reproduce.** Supply the two named patch executables, the pinned community rulesmd-original.ini and the pinned rtptool codec. Run the [reader](ra2-patch-audit.py) with those four paths, followed by an output directory. Python cryptography and Rust are required. The reader fingerprints all three data sources in the result, verifies the expected patch and codec hashes, compiles the codec in a temporary directory, checks the unpacked MIX hash and payload checksum, and validates each member extent before reading rules. The normalized section digest includes the ordered list of key/value pairs as compact ASCII-escaped JSON. Duplicate keys are retained. No raw game files are distributed. [Decoder source, pinned revision](https://github.com/bwrsandman/rtptool/blob/258d1750340917bcf1361a177b90abd16de40453/src/codec.rs) · [OpenRA MIX format reader](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Cnc/FileSystem/MixFile.cs) · [Comparator at its exact source revision](https://github.com/hamdirizal/red-alert-2-rules/blob/b66200ab0130a24bae8d8359caa6ab03bd78e8f7/rulesmd-original.ini)
