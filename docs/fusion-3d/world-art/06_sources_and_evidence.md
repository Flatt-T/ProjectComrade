## Source-reading cautions that affect implementation

Historical source enums, dormant code and modern remaster behavior are not interchangeable. The historian found that Red Alert's source includes a bridge-related Engineer block under `OBSOLETE`; that cannot establish active retail repair behavior. Likewise an enum naming an unusual theatre does not prove that theatre shipped. All theatre/bridge claims must record source revision, compilation context, edition and an observation fixture where the evidence is incomplete.

The 28 terrain families in the production contract are a required coverage taxonomy, with explicit source validation and expansion tasks. They are not an already-complete list of every source map. The source inventory and approved scope decisions determine the final production denominator.
