## Procedure

1. Read the locked reference manifest and catalogue schema. Confirm an exact legally accessible source profile, source/config hash and observation environment before extracting facts. If the profile is unavailable, list precise blocked evidence and perform only source discovery/classification that can be supported.
2. As this is an era work package, first generate bounded research leaves: one faction availability/production graph, at most 25 simple raw-definition classifications per intake leaf, and one complex entity or at most five closely related simple entities per behavior-evidence leaf. Give each leaf the relevant source excerpt/locator, profile, output schema, acceptance and reviewer. A coordinator must not claim an entire era was completed in one context window.
3. Create an unfiltered candidate census from active source/config enumerations, manuals, mission references and map object lists. Preserve raw IDs; classify buildable units, buildings/defenses, walls/gates, neutral tech/civilian objects, heroes, campaign-only units, support powers, upgrades, deployed/transformed forms, summoned/spawned children, projectiles, wrecks, unused/cancelled records and visual-only helpers.
4. Extract full faction availability and production graphs, including prerequisites, negative restrictions, expansion inheritance, capture access, tech upgrades, per-mode legality and one-per-player restrictions. Record economy/build timing, mobility/target layers and every signature interaction with source evidence.
5. Fork the pinned TS catalogue through explicit inheritance and record every added/replaced/removed definition, altered prerequisite and campaign gate. Do not duplicate inherited logical entities simply to increase counts.
6. Resolve GDI and Nod expansion units and support structures, including Juggernaut, Mobile EMP, Limpet Drone, Mobile War Factory, Cyborg Reaper, Mobile Stealth Generator and Fist of Nod candidate names, against actual rules/art data and production.
7. Inventory CABAL campaign units/structures and scripted set pieces, including Core Defender candidates; identify what is genuinely available versus a new Fusion-faction proposal. Treat Forgotten and environmental lifeforms independently of main playable factions.
8. Measure mobile factory deployment, mobile EMP/stealth, limpet attaching/reveal/removal, Reaper anti-infantry/anti-air behavior and snare effects, and environmental hazards. Resolve differences between expansion manual, base manual and patched build.
9. Verify random-map and environmental features mentioned in the converted manual text, including mutated landscapes, blue/green blossom growth, vein holes, ion storms and day/night; compare original PDF pages and shipped gameplay because OCR/mirror conversion is not sufficient proof.
10. For each behavior-critical entity create a repeatable observation fixture with initial state, input sequence, measured outcome, units/tolerance and video or event evidence where available. Measure movement/turning, acquisition/firing/reload, health/armor/damage, costs/build times, special ability state and death/ownership transitions. Unknown values remain explicit blockers for that entity.
11. Document geometry, silhouette, material, faction cues, required animation states, effects, audio and destruction as observable reference requirements; list original-asset production needs and distinct permission/provenance records. No sprite recolor or generic primitive may be counted as the final full-3D model.
12. Create a theatre/terrain/props register and terrain-mechanic matrix from shipped maps/assets. Record which bridges/ice/tunnels/water/cliffs/buildability/destructibles actually exist and which rules are still unverified. Route bridge/world features to RES-025 with exact map/build evidence.
13. Create a source-to-Fusion disposition for every entity and mechanic: faithful profile, authored adaptation proposal, campaign/scenario-only, reference-only, verified inactive alias/exclusion, or unresolved. Unsupported engine capabilities block affected entities; do not fake them with a generic unit type.
14. Reconcile candidate counts to final categories and compare manual roster, active definitions, producer menus and campaign/map references. Explain every discrepancy, alias and exclusion. Submit complete era package for independent review and emit the downstream per-entity implementation draft only from verified included records.
