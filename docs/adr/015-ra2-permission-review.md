# ADR 015 — Red Alert 2 integration and permission review

Reviewed 25 November 2026 for [THU-1360](https://linear.app/thunderchild-creative/issue/THU-1360), using [COMRADE 01](https://linear.app/thunderchild-creative/document/comrade-01-research-source-register-licensing-and-feasibility-gates-1d2fd8225a48), [COMRADE 03](https://linear.app/thunderchild-creative/document/comrade-03-game-pack-schema-complete-content-inventory-and-mechanics-fe2a2850984b) and [COMRADE 09](https://linear.app/thunderchild-creative/document/comrade-09-hosting-chatgpt-sites-evaluation-operations-and-cost-model-516180d0bb47).

## Decision

Defer a Classic Red Alert 2 adapter and its Yuri's Revenge extension. Each needs its own authorised builds, asset inventory and fidelity evidence. The existing original Fusion mode has a separate release contract under [ADR 010](010-fusion-engine.md).

## Evidence and handoff

A read-only registry query returned the pinned package identity and license. The response for version `0.80.0` was `UNLICENSED` with artifact integrity `sha512-gdKGuHMuCr+Y5z2n23NZfSe5AJvU9ffSjHHQZiKukeJ9MWsrcX1+4cjl1VWfZKRa60TWlTJNxX+OcxTOSYQm6Q==`. Developer documentation was checked separately from that metadata. [Registry record](https://registry.npmjs.org/@chronodivide%2fgame-api/0.80.0) · [Mod SDK](https://github.com/chronodivide/mod-sdk)

The authorized inputs and engine grant required for a headless gameplay trial were unavailable. This assessment used published interfaces and non-executable registry metadata. It records no engine execution or fidelity result.

1. Under THU-1333 and THU-1367, retain separate lawful base and expansion reference builds with edition, locale, executable and data hashes. Obtain documented permission for the intended engine and content use.
2. Under THU-1338 and THU-1361, validate an approved adapter with four independent name-only guests, Comrade-controlled public rooms and revocable invites, exact version negotiation, and a real self-hosted match.
3. Compare gameplay, stored state and replay for the two editions at pinned builds. Verify browser and headless agreement, reconnect and durable recovery before including any Classic claim in the release.
